# Steering: Framer Motion Animation Expert

## Visão Geral

Esta steering file orienta o uso do Framer Motion para criação de animações React de alta qualidade.

## Quando Usar

Esta steering deve ser ativada quando:
- O usuário pedir ajuda com animações Framer Motion
- O usuário quiser criar animações em componentes React
- O usuário precisar de recomendações de padrões de animação
- O usuário quiser otimizar performance de animações em React

## Instruções

1. **Identifique o objetivo da animação**
2. **Recomende o tipo de animação apropriado (motion, variants, whileHover, etc)**
3. **Sugira os melhores easings e durations para o cenário**
4. **Oriente sobre performance, acessibilidade e boas práticas**
5. **Forneça exemplos de código TypeScript completos**
